# Deskripsi UI User (Publik)

Warna aplikasi disusun dalam sistem yang konsisten. Warna brand utama adalah biru dengan gradasi lengkap dari sangat muda hingga sangat gelap. Biru sangat muda digunakan untuk latar aksen lembut, biru muda untuk highlight dan focus ring, biru standar untuk ikon dan tautan, biru tua untuk tombol utama, dan biru sangat gelap untuk hero, header admin, serta footer. Warna netral menggunakan skala abu-abu dari sangat terang untuk latar kartu dan area konten, abu-abu muda untuk border dan garis, abu-abu sedang untuk teks sekunder, hingga abu-abu sangat gelap untuk judul dan teks utama. Warna status menggunakan hijau untuk berhasil, merah untuk error dan hapus, serta oranye atau kuning untuk peringatan. Kontras teks terhadap latar selalu dijaga agar mudah dibaca.

Tipografi menggunakan satu keluarga sans-serif utama. Judul utama berukuran besar dengan ketebalan tebal dan tracking rapat. Subjudul berukuran sedang dengan ketebalan semibold. Teks paragraf berukuran standar dengan line-height longgar agar nyaman dibaca. Label form berukuran kecil hingga sedang dengan ketebalan medium. Teks bantuan dan keterangan menggunakan ukuran kecil dengan warna sekunder. Pada mobile, ukuran judul dan spacing dikurangi agar tidak memakan terlalu banyak ruang.

Tata letak publik menggunakan sistem container dengan lebar maksimum dan padding horizontal yang konsisten. Hero section menggunakan latar gradien biru gelap ke biru sedang dengan teks putih. Di dalam hero, terdapat dua kolom pada desktop: kolom kiri berisi label kecil uppercase, judul besar, paragraf, dan dua tombol CTA; kolom kanan berisi kartu statistik dengan latar putih transparan dan efek blur. Pada mobile, kedua kolom bertumpuk dan statistik ditampilkan sebagai grid tiga kolom kecil.

Section berikutnya menggunakan padding vertikal besar. Judul section diletakkan di kiri dengan tautan lihat semua di kanan pada desktop, sedangkan pada mobile bertumpuk. Grid kartu layanan dan portofolio menggunakan satu kolom di mobile, dua kolom di tablet, dan tiga kolom di desktop. Setiap kartu memiliki gambar di atas, judul, deskripsi singkat, dan tautan detail. Gambar menggunakan object-cover dengan rasio tetap agar tidak terdistorsi.

Halaman About menggunakan dua kolom: teks narasi di kiri dengan paragraf terpisah baris, dan gambar di kanan. Jika tidak ada gambar, layout menyesuaikan. Halaman detail layanan dan portofolio menampilkan judul besar, metadata, konten detail, dan galeri gambar. Galeri menggunakan grid dengan rasio kotak dan efek hover zoom ringan. Tombol kembali ke daftar diletakkan di atas konten.

Halaman kontak menggunakan dua kolom di desktop: formulir di kiri dalam kartu putih, dan informasi kontak di kanan dalam kartu gelap. Informasi kontak ditampilkan sebagai daftar label dan nilai. Formulir memiliki field nama, email, pesan, dan honeypot tersembunyi. Status sukses ditampilkan dengan alert hijau, error dengan alert merah. Error per-field ditampilkan tepat di bawah input terkait.

Navbar publik bersifat sticky dengan latar putih, bayangan tipis, dan z-index tinggi. Di desktop, logo berada di kiri, menu horizontal di tengah atau kanan, dan CTA di ujung kanan. Di mobile, logo di kiri dan ikon hamburger di kanan. Drawer mobile muncul dari kiri dengan overlay gelap dan animasi geser. Menu aktif ditandai dengan warna brand. Footer menggunakan latar gelap dengan empat kolom di desktop dan satu kolom di mobile, berisi logo, deskripsi, tautan cepat, dan kontak.

Admin panel memiliki tata letak berbeda dari publik. Sidebar gelap di kiri dengan lebar tetap berisi logo, nama panel, menu navigasi, badge jumlah pesan belum dibaca, dan tautan lihat website. Menu aktif menggunakan latar brand penuh dengan teks putih. Header putih di atas berisi tombol hamburger di mobile, judul halaman dinamis, nama dan email admin, serta tombol logout. Area konten menggunakan latar abu-abu muda dengan padding konsisten.

Dashboard admin menampilkan empat kartu statistik dalam grid responsif, masing-masing berupa link ke halaman terkait dengan angka besar dan label kecil. Di bawahnya terdapat kartu pesan terbaru dengan daftar item, judul, cuplikan pesan, dan tanggal. Halaman CRUD menggunakan header dengan judul, deskripsi, search input, dan tombol tambah. Tabel memiliki header abu-abu, baris dengan hover, dan kolom aksi di kanan berisi tombol lihat, edit, dan hapus. Modal form muncul di tengah dengan backdrop gelap dan animasi masuk. Form di dalam modal menggunakan spacing vertikal, field dengan label dan hint, serta tombol aksi di bawah.

Loading state ditampilkan dengan teks memuat atau spinner sederhana. Empty state menampilkan pesan yang menjelaskan belum ada data dan ajakan menambah. Error state ditampilkan dengan alert merah berborder. Semua interaksi memiliki transisi halus pada hover, focus, dan perubahan state. Tombol disabled memiliki latar abu-abu dan cursor not-allowed.

Aksesibilitas diperhatikan dengan label form yang eksplisit, atribut aria untuk alert dan dialog, focus ring yang jelas, serta kontras warna yang memadai. Pada mobile, target sentuh dibuat cukup besar dan spacing antar elemen diperlebar agar tidak salah klik. Semua gambar memiliki alt text yang sesuai, dan ikon dekoratif ditandai sebagai aria-hidden.
